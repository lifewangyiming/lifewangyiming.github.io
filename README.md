# Yiming Wang Personal Website

This is a static personal academic website that can be hosted with GitHub Pages.

## Preview Locally

Open `index.html` directly in a browser.

## Publish With GitHub Pages

1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Copy the contents of this `personal_website/` folder into that repository.
3. Commit and push to the `main` branch.
4. In GitHub, go to `Settings > Pages`.
5. Set source to `Deploy from a branch`, branch `main`, folder `/root`.
6. Your website will be available at `https://<your-github-username>.github.io/`.

## Files

- `index.html`: website content.
- `styles.css`: responsive visual styling.
- `assets/Yiming_Wang_CV.pdf`: downloadable CV.
- `assets/global_thermal_habitat.png`, `assets/littoral_trends.png`, `assets/lake_heatwaves.png`: research figures from the Ph.D. defense materials.
